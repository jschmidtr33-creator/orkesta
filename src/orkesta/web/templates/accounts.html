Configurar Google {% if google %}configurado{% endif %}

Se hace una sola vez para toda la organización. Luego cada persona conecta su Gmail con un clic.

  1. Entra a Google Cloud con tu cuenta (idealmente la de la empresa) y crea un proyecto llamado ORKESTA.
  2. Activa la API de Gmail con el botón «Habilitar».
  3. En Pantalla de consentimiento (Google Auth Platform) pon nombre «ORKESTA» y tu correo de soporte. En «Público» elige Interno si usas Google Workspace (no hay revisión de Google); si usas Gmail gratuito elige Externo y luego pulsa Publicar app para que la conexión no venza a los 7 días.
